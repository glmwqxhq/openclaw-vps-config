# OpenClaw VPS：2核2G就能长期挂机，从选配置到避坑一次说清

你搜 OpenClaw VPS，大概已经过了“这东西挺有意思”那一步。现在的问题是：它得一直在线，而我不能一直开着电脑。

OpenClaw（原 Clawdbot / Moltbot）本身就是按这个思路设计的。Gateway 跑在服务器上，状态和工作区都留在那台机器里，你从笔记本或手机通过控制界面、SSH 隧道或 Tailscale 连过去用。所以“要不要买 VPS”基本不用讨论，“买什么样的 VPS”才是真正要花的功夫。

## OpenClaw 到底吃多少资源

官方部署文档给的底线比大多数人想象的低：1 核 CPU、512MB 内存、1GB 硬盘就能启动。同一份文档下一页的推荐值是 2 核、1–2GB 内存、5GB 以上存储。这不是文档自相矛盾，而是“能启动”和“能一直跑”本来就是两件事。

几个具体的数字值得先记住：

- **Node.js 22 以上**。官方脚本推荐的版本是 Node 24。源码仓库用 pnpm workspace 管理依赖，直接 `npm install` 会失败。
- **Docker 部署要给容器留 2GB 内存**。这是目前最主流的自托管方式，容器里再跑一个浏览器沙箱，内存消耗会明显上一个台阶。
- **系统盘 40GB 起步更稳**。国内几家云厂商的一键部署教程给的都是这个数，原因是 `~/.openclaw/workspace`、会话记录、媒体文件、cron 日志会持续膨胀，30GB 不是不够用，是迟早会紧。

如果你只是想让一个 agent 接上 Telegram、跑点定时任务，2 核 2G 是绝大多数人真正落地的档位。1 核 1G 能跑，但要接受偶尔 OOM 和 CLI 命令卡顿的现实。

## 选 OpenClaw VPS 时，国内用户最容易踩的四个坑

这四个坑和 OpenClaw 本身没关系，是国内云厂商的产品结构决定的。

**第一，NAT 机器没有独立公网 IP。** 很多低价套餐默认只给 NAT 网络 + 端口映射，独立 IPv4 要另外加钱。OpenClaw 本身可以只绑 loopback、靠 SSH 隧道访问，所以 NAT 不是不能跑，但你会少掉“从任何设备直接用域名打开控制台”这个体验，而且端口映射数量是有限的。下单前看清楚有没有独立 IP、加一个多少钱。

**第二，大陆机房要备案，而且联网搜索功能会受限。** 想用域名访问大陆节点的机器得走 ICP 备案，流程以周计。更实际的问题是，不少教程都提到大陆节点访问境外服务会受限，而 OpenClaw 的很多能力恰恰依赖联网。选香港、韩国、日本、德国这类海外节点，省掉备案，也省掉后面一连串的连通性折腾。

**第三，流量是计费项，不是赠品。** 有的套餐标“不限流量”，代价是带宽低；有的套餐带宽很大，但给的是月度流量包，跑超了直接限速。海外的开源项目拉依赖、装浏览器沙箱、下模型文件，流量消耗比建站大得多，这一项别忽略。

**第四，账户隔离。** 官方安全文档说得很直接：如果用一台服务器给团队共用 agent，就别在这台机器上登录个人的 Apple / Google 账号，也别放个人浏览器配置和密码管理器。对个人用户来说，这条成立的方式是——不要拿你平时登着各种账号的主机去跑它。

## 按用途挑配置：三档建议

**只想让一个 agent 一直在线。** 2 核 2G，这是标准答案。雨云美国的 KVM 标准版 34 元/月，香港五区的 KVM 标准版 30 元/月（带宽还更大）。如果年付 7 折，摊下来每月二十多块。这个档位跑 Gateway、接 Telegram 或 WhatsApp、做点定时任务，余量是够的。

**要挂多个 agent、或者用到浏览器自动化。** 往上跳到 4 核 4G。雨云美国 KVM 进阶版 60 元/月、香港五区 63 元/月。多出来的一核一 G 不是给 Gateway 用的，是给 Chromium 沙箱用的——headful 模式下的浏览器实打实占内存。

**要在同一台机器上跑本地模型（比如 Ollama）。** 那就别在 VPS 上做这件事。4 核 8G、100 多块一个月的机器跑得动 7B 量化模型，但速度会让你重新考虑要不要用 API。真要在边缘做本地推理，用 Kimi 那类托管 API 更皮实，也便宜得多。4 核 8G 这个档位（雨云香港五区 103 元/月）更适合的场景是同时跑 OpenClaw + 一堆自动化服务。

带宽和流量方面，OpenClaw 的流量消耗主要在模型调用返回、网页抓取和媒体文件上。韩国一区给的是月度流量包（30GB 起），用完限速到 1M；香港五区给 1TB。如果你的 agent 会大量抓网页，后者的容错空间明显更大。

## 从买机器到 Gateway 跑起来

雨云支持一键部署 OpenClaw，整个流程比手动装省事：

1. 选好区域和机型，系统选 Ubuntu 22.04 或 Debian 12。
2. 加购独立 IP。除非你确定只用 SSH 隧道访问控制台，否则这一步别省。
3. 安装时勾选 OpenClaw 应用（或选 1Panel 这类面板再从中安装）。如果走手动路线，就是 `apt update`、装 Node.js 22+、`npm install -g openclaw@latest`，再 `openclaw onboard --install-daemon`。
4. 启动 Gateway。默认监听 `127.0.0.1:18789`，也就是说默认状态下只有本机能访问。
5. 从本地连过去：`ssh -L 18789:127.0.0.1:18789 root@你的服务器IP`，然后浏览器打开本地端口即可。

有一个细节容易被跳过：`gateway.bind` 一旦设成 `lan` 或 `tailnet`，Gateway 就会要求共享密钥（`gateway.auth.token` 或密码）。用 `openssl rand -hex 32` 生成一个长 token 再改绑定，比事后补救省心。

公网机器上线后最先被扫的是 SSH。把这几件事在装 OpenClaw 之前做完：改 SSH 端口、关掉密码登录只留密钥、装 fail2ban、用 UFW 只放行需要的端口。国内厂商的机器同样如此，没有哪个机房能让你省掉这一步。

## 常见问题

**OpenClaw 最低配置是什么？**
官方文档写的是 1 核、512MB 内存、1GB 硬盘起步，推荐 2 核、1–2GB 内存。但用 Docker 部署时建议给容器留 2GB 内存，国内厂商的一键部署教程也普遍按 2 核 2G、40GB 盘起步。要长期跑，按 2 核 2G 买。

**1 核 1G 的机器能跑吗？**
能。但 CLI 会明显变慢，挂的渠道和定时任务一多就有 OOM 风险。省下的每月十几块钱，通常不够抵消你花在处理内存问题上的时间。

**大陆机房的机器能用吗？**
技术上可以。但用域名访问要备案，且不少教程提到大陆节点访问境外服务受限。OpenClaw 的很多能力依赖联网，选香港、韩国、日本这类海外节点会省事很多。

**NAT 机器没有独立 IP 会影响使用吗？**
取决于你的用法。Gateway 默认只绑本机，靠 SSH 隧道访问完全没问题。但如果你想直接从手机浏览器打开控制台，或者要对外暴露端口，独立 IP 就是必要的，加一个 5 元/月起。

**流量用完了会怎样？**
按套餐类型不同。流量叠加型的套餐每月用不完的流量会结转到下个月，超量后限速（韩国一区限到 1M，部分区域限到 5M），可以单独购买流量包恢复速度。不限流量型则是带宽低一些但不计流量。

**不想要了能退吗？**
雨云支持 7 天内无理由退款，每个账号限 3 次。加上 1 元试用 1 天和月付选项，试错成本基本可以忽略。
